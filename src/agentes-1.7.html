# ws/contenido
Cuándo: crear o editar páginas, entradas o categorías.
Leer: docs/site.md (Contenido). Nada del tema.

## Pasos
1. Confirmá con el alumno qué quiere publicar.
2. Pasale el comando; él lo corre en el Site Shell.
3. Pedile solo el ID que devuelve.
4. Queda en borrador: que la revise y la publique.
5. Que verifique en el navegador (no leas HTML).

## Comandos
wp term create category "Flora y fauna"
wp post create --post_title=Carpincho --post_category=flora-y-fauna
wp post list --fields=ID,post_title,post_status

## Cierre (obligatorio)
- site.md: páginas/categorías nuevas.
- log.md: fecha · qué · quién lo ejecutó.
  • Cuándo: para que el índice lo encuentre.
  • Leer: el mínimo, explícito.
  • Pasos: con el alumno adentro.
  • Comandos probados, con salida corta.
  • Cierre: la tarea no termina hasta actualizar docs.

Apoyo

  • wp post create
  • wp term create
Mismo molde para tema.md y deploy.md. Los comandos van probados: un comando que falla hace que el agente explore, y eso es lo que queremos evitar.
