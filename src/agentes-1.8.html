Site Shell

  1. En Local, botón derecho sobre el sitio › Open site shell.
  2. cd wp-content/themes/reserva-child
  3. Probar: wp option get home

Fuera del Site Shell, wp no encuentra la base de datos de Local.

Apoyo

  • Comandos de wp-cli
# Mirar (salida corta)
wp theme list --status=active --fields=name
wp post list --post_type=page --fields=ID,post_title
wp term list category --fields=term_id,slug
wp plugin list --status=active --fields=name,version

# Hacer
wp post create --post_type=page --post_title="Cómo llegar"
wp option update blogdescription "Área protegida en Rivera"
wp rewrite flush

# Respaldar antes de algo grande
wp db export backup.sql   # *.sql en .gitignore
Ojo con db export: el .sql queda en la carpeta del tema, así que *.sql tiene que estar en el .gitignore antes del primer commit.
