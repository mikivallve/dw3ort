Bloque 4 · Práctica guiadaDe Local a Pantheon

# 1. En Local (Site Shell, carpeta del tema)
# LOCAL    = lo que devuelve: wp option get home
#            ej. http://lunarejo.local
# PANTHEON = https://dev-reserva-apellido.pantheonsite.io

wp search-replace LOCAL PANTHEON --all-tables --dry-run
wp search-replace LOCAL PANTHEON --all-tables --export=reserva.sql

--export escribe el archivo y no toca la base de Local. Que *.sql esté en el .gitignore.

  1. 2. Código (modo SFTP): en el wp-admin de Pantheon instalar Astra y los plugins, y subir reserva-child.zip. En el panel: Commit.
  2. 3. Base: Dev › Database / Files › Import › subir reserva.sql (hasta 100 MB directo).
  3. 4. Imágenes: comprimir wp-content/uploads en .zip e importarlo en Files.
  4. 5. Clear Caches y entrar con el usuario de Local.

Apoyo

  • wp search-replace
  • Pantheon: migración manual
El orden importa: código primero, después la base (que espera que el tema exista), después uploads. La base viaja con los usuarios: el admin y la contraseña de Local pasan a ser los de Pantheon, así que nada de admin/admin.
