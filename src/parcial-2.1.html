Bloque 3 · Jerarquía¿Qué plantilla usa WordPress?

WordPress busca de izquierda a derecha y usa el primer archivo que exista en el tema.

Se pide…Busca, en orden…
Una página /contactopage-contacto.php → page-{id}.php → page.php → singular.php → index.php
Una entradasingle-post.php → single.php → singular.php → index.php
Una categoría /category/floracategory-flora.php → category.php → archive.php → index.php
La página de entradas (blog)home.php → index.php
La portadafront-page.php → la de arriba que corresponda

Pregunta disparadora: "si creo page-contacto.php, ¿qué pasa con /nosotros?". Nada: sigue usando page.php. Esa es la idea para pasar UNA página.
