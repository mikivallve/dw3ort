get_header() vs. wp_head()

get_header() trae el archivo header.php. wp_head() va dentro del <head> y deja que WordPress y los plugins agreguen estilos, scripts y el <title>.

Personalizar vs. Ajustes

Personalizar muestra los cambios en vivo y maneja lo visual del tema: logo, ícono, menús y CSS adicional. Ajustes es la configuración del sitio: lectura, enlaces, escritura.

git commit vs. git push

commit guarda una versión en el repositorio local. push la sube al remoto (GitHub).

¿Por qué exportar desde Local?

El sitio son archivos y una base de datos. Copiar la carpeta deja afuera la base: entradas, ajustes, menús y usuarios. El export de Local lleva las dos cosas.
