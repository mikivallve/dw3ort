Bloque 1CMS vs. sitio estático

Sitio estático HTML + CSS

  • Cada cambio es editar un archivo a mano.
  • El contenido y el diseño viven juntos en el mismo .html.
  • Para cambiar el menú en 10 páginas, se edita 10 veces.

CMS WordPress

  • Datos en una base de datos (MySQL / MariaDB).
  • Presentación en un tema (PHP + HTML + CSS).
  • Panel (/wp-admin) para que cualquiera edite sin tocar código.

Base de datos → PHP arma la página → el navegador recibe HTML

5 min. Conectar con lo que ya saben: el HTML que el navegador recibe es el mismo; lo que cambia es quién lo arma.
