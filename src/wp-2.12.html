El truco

Pedir el contenido por componente visual: la respuesta ya viene con la forma de los bloques.

Prompt de ejemplo

Actúa como redactor UX. Necesito estructurar una
sección de servicios para un sitio web de [rubro].
Devuélveme el contenido para una grilla de 3 columnas.
Para cada columna proporciona:
1) Un título corto,
2) Una descripción orientada a beneficios de 25 palabras y
3) El texto exacto para un botón de acción.

Cambiar el rubro y probarlo con la grilla que acaban de armar.

Parte de los 25 min de IA. Comparar resultados entre dos alumnos con distinto rubro.
