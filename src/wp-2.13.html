Bloque 3IA para el CSS que falta

Cuando Gutenberg no tiene el ajuste (una sombra, una transición), se le pide a la IA un snippet chico.

1. Ponerle una clase al bloque

Bloque › Avanzado › Clase(s) CSS adicional(es): tarjeta

2. Pegar el CSS

  • Tema clásico (Astra): Apariencia › Personalizar › CSS adicional.
  • Tema de bloques: Apariencia › Editor › Estilos › CSS adicional.
.tarjeta {
  box-shadow: 0 8px 24px rgb(0 0 0 / .12);
  transition: transform .2s ease;
}
.tarjeta:hover {
  transform: translateY(-4px);
}

Prompt: "Dame CSS para la clase .tarjeta: sombra suave y que suba 4px al pasar el mouse. Solo el CSS."

Cierra el bloque 3 (min 165). Insistir en que lean el CSS antes de pegarlo.
