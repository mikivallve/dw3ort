Bloque 4IA para el CSS que falta

Cuando Gutenberg no tiene el ajuste (una sombra, una transición), va CSS. Lo escriben ustedes; la IA, en modo tutor, les dice qué propiedades mirar y revisa lo que escribieron.

1. Ponerle una clase al bloque

Bloque › Avanzado › Clase(s) CSS adicional(es): tarjeta

2. Escribir el CSS y pegarlo

  • Tema clásico (Astra): Apariencia › Personalizar › CSS adicional.
  • Tema de bloques: Apariencia › Editor › Estilos › CSS adicional.
.tarjeta {
  box-shadow: 0 8px 24px rgb(0 0 0 / .12);
  transition: transform .2s ease;
}
.tarjeta:hover {
  transform: translateY(-4px);
}

Prompt: "Quiero que .tarjeta tenga una sombra suave y suba 4px al pasar el mouse. No me des el código: decime qué propiedades mirar. Después revisá lo que escriba." El código de arriba es a lo que tienen que llegar.

Cierra el bloque 4 (min 160). Modo tutor: la IA no escribe el CSS, lo revisa. Si a alguien le da el código igual, mirar si cargó las reglas del modo tutor en su AGENTS.md.
