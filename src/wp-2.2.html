Crear el sitio

  1. + Create a new site → nombre del sitio.
  2. Entorno Preferred (Nginx, PHP y MySQL recientes).
  3. Usuario y contraseña de admin: no admin/admin.

Qué levanta Local

  • Servidor web: Nginx o Apache.
  • PHP: se elige la versión por sitio.
  • Base de datos: MySQL, con Adminer para mirarla.
  • WP Admin + One-click admin para entrar sin login.
