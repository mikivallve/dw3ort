Bloque 2El Loop

[ El usuario pide una URL ]
            ▼
[ WP consulta la base de datos ]
            ▼
[ ¿Hay entradas? have_posts() ]
     ▼ Sí              ▼ No
[ the_post() ]    [ 404 / vacío ]
     ▼
[ Título, contenido, metas ]
     ▼
[ ¿Hay más? Repetir ]

El Loop es un while de PHP que recorre lo que devolvió la consulta y le aplica las etiquetas de plantilla a cada entrada.

<?php if ( have_posts() ) : ?>
  <?php while ( have_posts() ) :
    the_post(); ?>
    <h2><?php the_title(); ?></h2>
    <p>Por <?php the_author(); ?></p>
    <?php the_content(); ?>
  <?php endwhile; ?>
<?php else : ?>
  <p>No hay contenido.</p>
<?php endif; ?>
20 min. La URL decide la consulta: /contacto/ trae 1 página, /category/noticias/ trae N entradas. El mismo Loop sirve para las dos.
